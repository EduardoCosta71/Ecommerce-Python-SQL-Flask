# DuTech — E-commerce

## Sobre o Projeto

O DuTech é um projeto de e-commerce desenvolvido com Python e Flask, com o objetivo de criar uma loja virtual de produtos de tecnologia.

A aplicação conta com uma estrutura de back-end integrada ao banco de dados SQL Server, permitindo o gerenciamento de produtos e categorias.

O projeto está em desenvolvimento, com foco na construção da área do cliente e na implementação das funcionalidades da loja.

## Tecnologias Utilizadas

- Python
- Flask
- SQL Server
- HTML5
- CSS3
- Git e GitHub

## Funcionalidades

- Cadastro e gerenciamento de produtos.
- Listagem de produtos por categoria.
- Pesquisa e organização de produtos.
- Integração com banco de dados SQL Server.
- Estrutura de cadastro e login de usuários.
- Desenvolvimento da interface da loja virtual.

## Estrutura do Projeto

O projeto utiliza Flask para organizar as rotas e integrar a aplicação ao banco de dados SQL Server.

A estrutura é organizada em módulos, separando as funcionalidades da aplicação para facilitar a manutenção e a evolução do sistema.

## Objetivo

Desenvolver uma aplicação de e-commerce para praticar conhecimentos em desenvolvimento Back-end, integração com banco de dados relacionais e construção de aplicações web utilizando Python e Flask.

## Status do Projeto
